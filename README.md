# Eliminación Gaussiana Densa ($12 \times 12$): Costo Operacional Mínimo y Control de Mantisa

Implementación instrumentada de eliminación gaussiana con pivoteo parcial escalado, conteo exacto de FLOPs y refinamiento iterativo en precisión extendida para resolver un sistema lineal denso mal condicionado ($\kappa_2(A) \approx 3.08 \times 10^{13}$).
